# Core API docs

The CLI is a thin wrapper over the `octothorpes` core package (entry point:
`packages/core/client.js` in the octothorp.es repo). The API documentation
lives with the core package, not here:

- `docs/core-api-guide.md` in the octothorp.es repo — full API reference
- `.claude/skills/octothorpes/package.md` — package overview and `createClient` usage

A stale copy of the guide previously lived in this file; it referred to the
old `@octothorpes/core` name and `index.js` entry and has been removed rather
than maintained in two places.
